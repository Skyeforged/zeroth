# Zeroth

Zeroth is a frontend-only Vue 3 + Vite + TypeScript app (Pinia, Vue Router, hand-written UI components in `src/components/ui/`, no component library) for Arknights: Endfield. It is a collection of features, each in `src/features/<name>/` with routes under `/<name>/...` and a home page at `/`. Current feature: **Essence** (`src/features/essence/`: Tracker and Farming Optimizer). Hosted as a static site on GitHub Pages.

**Read before changing anything:**

- `docs/README.md`: stack, hosting, feature folders and routing, data contract, file map
- `docs/essence-tracker.md`: tracker rules, status logic, persistence
- `docs/essence-optimizer.md`: engraving rules, scoring algorithm, UI
- `docs/data-sync.md`: the weapon sync script, source tracking (`sourceRefs`, `sources.json`, `gaps.json`, `manifest.json`), safety rules

## Conventions

- Game data in `src/data/*.json` uses **unique snake_case ids only** (for example `atk_boost`). Display names live in `src/locales/en.json`; render them with `nameOf()` (`src/lib/i18n.ts`).
- Static SPA only: **no SSR**, hash-history routing, no backend. Everything must work on GitHub Pages under a base path.
- The game rules in `docs/` were confirmed by the user. **Do not assume game mechanics: ask the user** if something is unclear.
- Keep pure logic (`src/lib/*`) free of Vue imports so it stays unit-testable.
- When you change rules, scoring, storage keys or the data contract, update the matching doc in `docs/`.
- Stats (`stats.json`, locale names) are real. `weapons.json`, `sources.json`, `gaps.json`, `manifest.json` and the locale `weapons` map are **generated by `npm run sync:weapons`: never hand-edit them** (until the user runs the script, `weapons.json` is still `sample_*` placeholder). `alluviums.json` is **user-owned** (the user enters `slot2Pool` by hand); `npm run sync:alluviums` only **adds** new locations (with `slot3Pool` from the wiki and an empty `slot2Pool`) and never modifies existing entries. The user fills `slot2Pool` with the interactive `npm run edit:alluviums` tool (the agent must not run it). Do not hand-fill or edit it unless asked (until the user runs the sync, it is `sample_alluvium_*` placeholder).
- 3-star weapons have no slot 2 (`essence.slot2` is optional); slot 1 and slot 3 are always present.
- Do not run the sync scripts unless the user asks (it hits the network and rewrites data files).

## Working agreements (from the user)

- Do not compile, build or run tests (`npm run build`, `npm run test:unit`, and similar) unless the user explicitly asks. Writing code never implies permission to build or test it.
